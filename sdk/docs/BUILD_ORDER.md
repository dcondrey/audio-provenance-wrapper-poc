1. UNIT 0 — REPO SKELETON. pnpm workspace, TS 5.x strict (noUncheckedIndexedAccess on; the DSP code is index-heavy and this is where off-by-ones die), vitest, eslint, tsup. Eight package stubs under the @writerslogic/audio-provenance-* scope plus the @audio-provenance/sdk alias package. CI runs typecheck, lint, test, build, pack in that order — the same order locally, including the pack step, so a push is not a coin flip against a CI round trip. No source logic.
2. UNIT 1 — CANON, TESTED AGAINST PYTHON, NOT AGAINST ITSELF. canonicalJsonBytes, parseCanonicalJson, f64, pythonFloatRepr, legacyAsciiJsonBytes, sha256 helpers, HashChain. FIXTURE PROVENANCE RULE: the negative vectors may NOT come from this package's own writer or docstrings. A generator script drives /Volumes/A/audio-provenance/.venv/bin/python over a corpus (every real manifest in the POC plus a fuzz corpus) and emits expected bytes; the TS test asserts byte equality against that file. Vectors that MUST be in it, each already confirmed differentially in this session: 1.0 -> "1.0" not "1"; 1e16 -> "1e+16" not "10000000000000000"; 1e-5 -> "1e-05" not "0.00001"; 1e-7 -> "1e-07" not "1e-7"; -0.0 -> "-0.0" not "0"; NaN/Infinity throw; a lone surrogate throws (Python raises UnicodeEncodeError, JSON.stringify silently emits an escape); and the astral key-sort vector {z, U+FFFD, U+1F3B5}, where Python orders z < U+FFFD < U+1F3B5 and Array.prototype.sort orders z < U+1F3B5 < U+FFFD — sort by UTF-8 bytes, never by Array.sort. Also assert legacyAsciiJsonBytes reproduces generator.py:425's implicit ensure_ascii=True form on non-ASCII input. FIRST because every signature in the system is a signature over bytes this package produced, and a divergence here is silent.
3. UNIT 2 — MANIFEST VOCABULARY. Types, builder, validateManifest as a direct port of daemon/schema.py validate_manifest_invariants, the ProofLevel lattice, capProofLevel (a floor, not a max), degrade(). The UnverifiedManifest brand and admitManifest(). Ported invariants tested against the POC's own manifests as fixtures. No crypto, no I/O.
4. UNIT 3 — CRYPTO AND TRUST. Ed25519 via node:crypto's JWK OKP path, X509 chain validation against configured anchors with the POC's leaf profile (CA:FALSE, critical digitalSignature, emailProtection EKU, AKI matching issuer SKI), TrustStore, revocation. CROSS-LANGUAGE GATE: a Python-generated signature must verify in Node AND a Node signature must be byte-identical to Python's over the same manifest. Assert here that a self-generated key yields identityProofLevel unknown_unobserved and identity null — the invariant the whole product rests on.
5. UNIT 4 — AUDIO AND PCM. WAV/RIFF/RF64 and AIFF parse+write, header parse for MP3/M4A/FLAC/Ogg, the DecoderPort interface with an ffmpeg child-process adapter, mono-sum window iteration, contentSha256 over the canonical PCM payload. Test that retagging metadata does not change contentSha256 while a single flipped sample does.
6. UNIT 5 — REGISTRY. RegistryBackend interface, FilesystemRegistry, MemoryRegistry, HttpRegistry, ChainRegistry, config discovery. THE ONE TEST THAT MATTERS: an unreachable or malformed backend throws RegistryUnavailableError and a miss returns null, so a network fault can never become a verdict. Built before Trace because Trace's ladder is defined in terms of this interface.
7. UNIT B0 — BENCH HARNESS, AND ITS SELF-TEST. THE BENCH COMES BEFORE THE WATERMARK. A watermark that only round-trips clean audio is worthless, and the bench is the only thing that detects that. Corpus loader, the channel simulators (codec matrix via ffmpeg, resample, speed, gain, dither, clip, LUFS normalization, band-limit, RIR convolution), the seeded (track, channel, seed) triple so any failure is reproducible from the tuple alone, the JSON matrix emitter, and the ratchet check. CRITICAL SELF-TEST, without which 'bench first' is ceremonial: run the harness against a STUB embedder that writes noise and a STUB detector that returns a fixed payload. The null test MUST fail loudly and the channel matrix MUST show zero. A harness that cannot fail a known-bad implementation has not been validated, it has only been executed.
8. UNIT C0 — CALIBRATION, BEFORE ANY REAL EMBEDDER EXISTS. Measure sigma_d, the residual noise on the trimmed-mean pair-difference statistic, over the stratified corpus, per content class. Set DELTA = 4.0 * sigma_d clamped to [0.5, 1.2] nepers; 0.8 is the pre-registered prediction. Also measure the OLA leakage bound that unit W4's two-pass closure must beat. THIS IS THE HIGHEST-VALUE CHEAP MEASUREMENT IN THE WHOLE PLAN: panel 1's sharpest criticism of the losing candidate was that every downstream number hung on one uncited noise constant, and that criticism applies verbatim to this design. If sigma_d comes in high, take the pre-specified fallback (frames_per_bit 2 -> 3 -> 4, block 9.66 -> 14.49 -> 19.32 s) rather than redesigning; that is why the ladder is fixed in the spec now.
9. UNIT W1 — THE INVARIANT TESTS, BEFORE THE CODEC. Pure functions for cells, pairs, the guard mask, D[t,k], and the trimmed mean, plus the two deterministic tests that are this design's whole reason for winning: (a) a scalar gain g leaves d[s] bit-stably unchanged to within float epsilon; (b) an LTI response smooth over 86 Hz leaves d[s] unchanged to first order. These pin the property that no other candidate could test on day one. If either fails, the design is wrong and nothing downstream is worth writing.
10. UNIT W2 — DSP PRIMITIVES. Radix-2 complex FFT-512 with the real-input split step, twiddle/bit-reversal tables, sqrt-Hann, sliding median and MAD ring buffers, CRC-32C, ChaCha20 keystream, the K=9 rate-1/3 convolutional encoder and soft-decision Viterbi, the 24x12 interleaver. Each tested standalone: the Viterbi against a known AWGN BER curve, CRC-32C against published vectors, the FFT against a naive DFT.
11. UNIT W3 — STREAMING SPECTROGRAM. Chunked STFT with the 1.5 s overlap that carries the 129-frame sliding median across chunk boundaries. Test chunk-boundary equivalence against a whole-file reference to float epsilon. Isolated because the ring-buffer and overlap bookkeeping is where the bugs will be, not in the FFT, and because the 340 MB whole-file magnitude array makes this mandatory rather than an optimization.
12. UNIT W4 — EMBEDDER. Dithered QIM targeting, the closed-form antisymmetric gain application, puncturing, two-pass OLA closure asserted under DELTA/20, the PEAQ guard that lowers DELTA and RECORDS the robustness reduction in the manifest. Round-trip against a synthetic detector stub only; the real detector is next.
13. UNIT W5 — DETECTOR. Hop-64 analysis, per-rho cell-edge rescaling from one FFT, normalization and reliability weights, preamble acquisition, fine-rho pilot scoring, QIM soft demodulation, Viterbi, CRC, confidence classes. Run the full bench IMMEDIATELY — it already exists and is already self-tested, so the first honest robustness number arrives the day the detector compiles rather than a month later.
14. UNIT N1 — THE NULL TEST, WHICH IS A GATE AND NOT A REPORT. Detector over 1,000 un-watermarked tracks crossed with every channel (~24,000 runs) at the production tau_sync and production CRC-32C. PASS = ZERO payload accepts. A single accept invalidates the section 9 arithmetic and forces a wider CRC or higher tau_sync; it is not waived as an outlier. Also instrument the observed sync-candidate count per clean track against the predicted ~26; a large discrepancy means tau_sync was calibrated on the wrong noise distribution. THIS UNIT PRODUCES falsePositiveRateAtMatch. Until it passes, soft-binding `verified` cannot ship, because there is no honest number for that required field.
15. UNIT 6 — TRACE. The five-rung ladder, candidate admission with the canonicality assert before signature verification, binding evaluation, arbitration, the four status predicates and the soft-coverage guard. Built after the watermark and the null test because rung 4's proof levels and match semantics are defined in terms of numbers only those units produce.
16. UNIT 7 — FINGERPRINT (rung 5). Landmark hashing, the index, offset-histogram scoring with client-side re-derivation of any server-supplied score. Last of the recovery work because it is default-off and can never produce `verified`.
17. UNIT 8 — SDK FACADE AND CLI. verify/sign/embed/inspect wired to the units above; the CLI renderers, exit codes, and `audio-provenance bench` as a named subcommand rather than an orphan script in scripts/. Golden-output tests for the brief's exact invocation.
18. UNIT B4 — TRANSPARENCY CAMPAIGN. PEAQ basic ODG over all 200 embedded tracks, then a 12-subject blinded ABX on the 10 worst. Only on completion may measuredTransparency stop being null. Last because it gates a claim, not a capability.
